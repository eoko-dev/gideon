Backup & Restore

Export configurations and database backups, or restore from previous backups.

Export

Configuration (JSON)

Export all global settings, channel configs, persona templates, and user preferences as a human-readable JSON file.

Excludes: messages, threads, API keys, trivia data, reminders.

Full Database (SQLite)

Download a complete copy of the database, including all messages, trivia stats, and encrypted API keys.

Note: Encrypted API keys require the same ENCRYPTION_MASTER_KEY to decrypt.

Import / Restore

Import Configuration

Upload a previously exported JSON configuration file to apply settings.

Drag & drop JSON file here or browse

Restore Database

Upload a previously exported SQLite database file to fully restore the bot's state.

Warning: This will REPLACE your entire database. All current data will be lost. A backup of the current database is saved automatically before restore.

Drag & drop SQLite file here or browse

Confirm Database Restore

This action cannot be undone.

Your entire database will be replaced with the uploaded backup. All current messages, trivia stats, reminders, and other data will be lost.

A backup of the current database will be saved automatically before restore.
